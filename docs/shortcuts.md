# Keyboard shortcuts

Shortcuts are implemented by the GUI milestone by milestone; this file is the
contract they implement.

## View

| Shortcut | Action |
|----------|--------|
| `F` | Fit image to window |
| `1` | Zoom 100% (1:1 pixels) |
| `+` / `-` | Zoom in / out |
| Space + drag | Pan (temporary hand tool) |
| Mouse wheel | Zoom at cursor |
| Middle-drag | Pan |

## Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Redo |
| `Ctrl+S` | Save `.pfg` sidecar |
| `Ctrl+E` | Export |
| `Ctrl+O` | Open image |
| Double-click slider | Reset slider to default |

## Tools

| Shortcut | Action |
|----------|--------|
| `C` | Crop tool |
| `B` | Brush mask |
| `G` | Linear gradient mask |
| `R` | Radial gradient mask |
| `V` | No tool (navigate) |
| `Enter` | Apply crop |
| `Esc` | Cancel crop / close dialog |

## Compare

| Shortcut | Action |
|----------|--------|
| `\` (hold) | Show original (before) |
| `P` | Toggle split (before/after) view |
